# Meme Fact

**Meme Fact** is an offline "True or False" quiz in your browser. 4000 cards (2000 facts + 2000 myths) in English and Russian. No AI, no internet, no data collection.

## What is it

- 🎯 **Fact of the day** — a new fact every day.
- 🔥 **Streaks** — come back every day to keep your streak.
- 🏆 **37 achievements** — from "First flame" to "Fact King".
- 📈 **100 levels** — from "Novice" to "Absolute Mind".
- 📚 **Collection** — all facts you've opened are saved locally.
- 🎲 **4000 cards** — 2000 facts and 2000 myths in two languages.

## Privacy

- **100% offline** — after installation, the extension needs no internet.
- **Zero data collection** — no analytics, no trackers, no accounts.
- **Everything is local** — progress is stored in `chrome.storage.local`.

## Install

- **Firefox:** [Add-ons](https://addons.mozilla.org/firefox/addon/meme-fact/) *(pending review)*
- **Chrome / Opera / Edge:** [Chrome Web Store](https://chrome.google.com/webstore/) *(pending review)*
