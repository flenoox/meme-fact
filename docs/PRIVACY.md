# Meme Fact — Privacy Policy

**Last updated: October 27, 2026**
**Author:** Eliot Ogate — me@im2222.ru

## 1. What data we collect

**None.** Meme Fact does not collect, transmit, or store any personal data.

## 2. What is stored locally

The extension uses `chrome.storage.local` (browser-local storage) to:
- Save progress (XP, level, streak).
- Save opened facts (collection).
- Save preferences (language).

This data **never leaves your device** and is not sent to any server. You can delete it at any time by clearing the extension's data.

## 3. Internet connection

The extension works **fully offline**. It makes no network requests except when the user explicitly clicks:
- **"Share"** — opens an external site (`t.me`, `wa.me`, `vk.com`, `x.com`, `reddit.com`).
- **"Buy me a coffee"** — opens `boosty.to`.

These actions are **voluntary** and are not related to any data transfer from the extension.

## 4. Analytics and trackers

**None.** There is no Google Analytics, Facebook Pixel, Sentry, or any other SDK.
